# عدسات عمان

صفحة هبوط حديثة لمحل «عدسات عمان» للنظارات: رحلة تمرير سينمائية بفيديو ثلاثي الأبعاد للنظارات، شريط علامات تجارية متحرك، عرض عصري للمنتجات، ولوحة إدارة لإضافة المنتجات وحذفها. الواجهة عربية (من اليمين لليسار) ومصممة للهاتف أولاً.

- **الواجهة:** React 19 + Vite 7 + TypeScript، تُبنى إلى ملفات ثابتة (مع تصيير مسبق للصفحة الرئيسية لسرعة الفتح).
- **الخلفية:** ملفات PHP صغيرة في `public/api` تحفظ المنتجات في ملفات JSON وترفع الصور إلى مجلد `uploads`. لا تحتاج قاعدة بيانات.
- **الاستضافة:** أي استضافة Hostinger تدعم PHP 8.1 أو أحدث (الخطط المشتركة تكفي).

## التشغيل محلياً

```bash
npm install
npm run dev        # الواجهة فقط، تعرض المنتجات الافتراضية
```

لتجربة النسخة الكاملة مع لوحة الإدارة (يلزم PHP 8.1+ على جهازك):

```bash
npm run build
cp dist/api/config.sample.php dist/api/config.php   # ثم غيّر كلمة المرور داخله
php -S 127.0.0.1:8080 -t dist
```

افتح `http://127.0.0.1:8080` للموقع و`http://127.0.0.1:8080/admin/` للوحة الإدارة.

## النشر على Hostinger (يدوياً)

1. شغّل `npm run build`. يمكنك ضبط عنوان موقعك للروابط الاجتماعية: `SITE_URL=https://yourdomain.com npm run build`.
2. من hPanel افتح **مدير الملفات** ثم `public_html`، وارفع **محتويات** مجلد `dist` (وليس المجلد نفسه). تأكد من رفع الملفات المخفية مثل `.htaccess`.
3. على الاستضافة انسخ `api/config.sample.php` إلى `api/config.php` واكتب فيه كلمة مرور قوية للوحة الإدارة.
4. اضبط إصدار PHP على 8.1 أو أحدث من **Advanced ← PHP Configuration**، وتأكد أن إضافة `fileinfo` مفعّلة (تكون مفعّلة افتراضياً).
5. فعّل شهادة SSL المجانية للدومين. ملف `.htaccess` يحوّل الزوار إلى HTTPS تلقائياً.
6. افتح `https://yourdomain.com/admin/`، ادخل بكلمة المرور، ثم أضف رقم واتساب والعنوان وساعات العمل وابدأ برفع منتجاتك.

> عند أي تحديث لاحق أعد رفع محتويات `dist` فقط. لا تحذف `api/config.php` ولا مجلدي `data` و`uploads` لأنهما يحويان كلمة المرور والمنتجات المضافة.

## النشر التلقائي من GitHub (اختياري)

1. ارفع المشروع إلى مستودع GitHub:
   ```bash
   git remote add origin https://github.com/<حسابك>/adasat-oman.git
   git push -u origin main
   ```
2. من **Settings ← Secrets and variables ← Actions** أضف الأسرار: `FTP_SERVER` و`FTP_USERNAME` و`FTP_PASSWORD` (بيانات FTP من hPanel ← Files ← FTP Accounts).
3. أضف المتغيّرات (Variables): `SITE_URL` (مثل `https://yourdomain.com`)، و`FTP_DIR` إن كان مجلد النشر غير `./public_html/`.
4. عند كل دفع إلى الفرع `main` يبني GitHub الموقع ويرفعه. الملفات `api/config.php` و`data/` و`uploads/` لا تُلمس. أنشئ `config.php` مرة واحدة يدوياً كما في الخطوة 3 أعلاه.

بدون أسرار FTP يكتفي سير العمل بالبناء ويحفظ الناتج كملف قابل للتنزيل (Artifact).

## الأداء على الهاتف

- **الحاسوب:** رحلة التمرير تحرّك الفيديو مع التمرير (محرك `scroll-scrub`).
- **الهاتف:** لا يُحمَّل هذا المحرك أصلاً. تظهر حلقة فيديو خفيفة بتشغيل تلقائي تتوقف عند الخروج من الشاشة، وبطاقات قصة قابلة للسحب، ومنتجات في شبكة من عمودين، وشريط إجراءات سفلي ثابت.
- لا يوجد blur ولا تحويلات ثلاثية الأبعاد أثناء التمرير على الهاتف، والخط يُحمَّل من الموقع نفسه.
- يُحترم إعداد «تقليل الحركة» في الجهاز (تظهر صورة ثابتة بدل الفيديو).

## تعديل المحتوى

| ماذا تريد | أين |
|---|---|
| أسماء العلامات التجارية في الشريط المتحرك | `src/site-config.ts` (القائمة `BRANDS`) |
| المنتجات الافتراضية قبل إضافة منتجاتك | `src/site-config.ts` و`public/api/_lib.php` (الدالة `default_products`) |
| نصوص فصول الرحلة (الرؤية، الإطارات، العدسات) | `src/scroll-scrub-scenes.ts` |
| نصوص الخدمات | `src/components/site/sections.tsx` |
| الألوان | المتغيرات في أعلى `src/site.css` |
| الخط | Readex Pro محلي في `public/assets/fonts` (لا يعتمد على Google) |
| فيديو الرحلة على الحاسوب | `public/assets/world/scene-0*.mp4` (ثلاثة مقاطع متتالية تتحرك مع التمرير) |
| فيديو الهاتف | `public/assets/world/hero-mobile.mp4` وصورته `hero-mobile-poster.jpg` (حلقة خفيفة بتشغيل تلقائي، 1 ميغابايت) |

الأسعار والمنتجات الستة الافتراضية أمثلة فقط. احذفها من لوحة الإدارة بعد إضافة منتجاتك الحقيقية.

## الأمان

- لا تُرفع كلمة المرور إلى GitHub: الملف `public/api/config.php` وملفات `data/*.json` ومجلد `uploads/` مستثناة في `.gitignore`.
- مجلد `data` محمي بـ `.htaccess` ويمنع الوصول المباشر، ومجلد `uploads` يمنع تنفيذ PHP، ولا تُقبل إلا صور JPG وPNG وWebP حتى 5 ميغابايت.
- كلمة مرور الإدارة تُرسل عبر HTTPS فقط، لذلك فعّل SSL قبل استخدام اللوحة.
